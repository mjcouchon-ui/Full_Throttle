## Source detail

These preserve the submitted artwork, character likenesses, colors and wording. They were cropped out of a 1774 x 887 sheet. Each ad supplies approximately 580 x 290 source pixels, substantially less detail than the individually generated Set02 designs. The 2048 x 1024 files are Lanczos upscales with a small aspect correction to fit the existing 2:1 billboard faces. No additional detail was generated and no text was re-typeset.

Use the large headlines as the primary drive-by read. Small print and portraits will soften on a close inspection; an in-level test is required before treating these as final close-up artwork. A 1024 x 512 cap may be enough for these particular sources and saves memory if the gameplay view does not reveal a difference.

## Unreal import and optimization

**Use `import ft_billboards; ft_billboards.build()` (`Content/Python/ft_billboards.py`) instead.** It builds both sets into `/Game/Maps/Bayshore/Billboards/` (textures, `M_BB_Printed`, the instances and the `SM_BB_*` sign meshes) and is what Level 1's track places. The importer described below writes to a different folder (`.../Billboards/Set01/Textures`), so running it would create duplicate assets; it is kept only as the pack's original hand-off.

The optional `unreal/import_billboards.py` imports the nine `textures_2k/` PNGs into `/Game/Maps/Bayshore/Billboards/Set01/Textures`, creates one shared Default Lit material and nine material instances, and does not alter the map. Existing destination assets cause an early stop rather than an overwrite. Run it with Unreal's Execute Python Script command. Its syntax has been checked locally; it has not been executed in Unreal.

The importer sets BC7 compression for the Windows target, sRGB on, World texture group, a full mip chain, streaming allowed, Clamp X/Y, LOD Bias 0 and Maximum Texture Size 2048. The material uses Base Color with roughness 0.75, metallic 0, no transparency, and no emissive. Verify the cooked target format and gameplay appearance in the editor.

At full residency, nine BC7 2048 x 1024 textures with mipmaps are approximately 24 MiB in total. If capped to 1024 x 512, they are approximately 6 MiB. These are texture block-compression estimates, not measured GPU results. Texture streaming can reduce residency at distance.

## Geometry and placement

The inspected project is `K:/Full Throttle/UE/full-throttle-unreal`. Its `ft_city.py` builds the current `SM_Billboard` artwork from colored geometry. The sign face is 1200 x 600 cm with a bottom height of 560 cm and faces local -X. The optional `meshes/SM_BB_FaceOverlay.obj` matches that face, has full-face UVs, and sits at local X=-20 cm to clear the original decorative geometry. Import at scale 1 and verify orientation and UVs before placing it.

Signs are generated by a prop rule in `FTTrack.cpp`. The overlay must receive each sign's transform, or its face can be incorporated into new billboard mesh variants. This pack does not change those prop rules, place actors, or replace any existing sign asset.

## Contents and validation

- `textures_2k/`: nine separate 2048 x 1024 RGB PNGs with embedded sRGB profiles, no alpha.
- `source_crops/`: original-resolution ad faces after removal of the shared gutters.
- `originals/`: the exact submitted sheet.
- `prompts/`: the original nine-design generation prompt.
- `meshes/`: optional two-triangle face overlay.
- `unreal/`: optional texture/material importer.
- `manifest.json`: source crop coordinates, dimensions, SHA-256 hashes and processing details.
- `preview.jpg`: review contact sheet; do not import this as a production texture.

Checks cover PNG decoding, dimensions, RGB format, sRGB profiles, crop borders, visible copy, archive integrity and importer syntax. They do not cover engine import, runtime performance or readability at gameplay speed.
