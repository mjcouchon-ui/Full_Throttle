# HOW IT KEEPS ITS PLACE
# - Short takes. Each starts with FTBossNow (FLOW:1003): road, barrels and hazards cleared, the car back at the top of
#   THE FINALE (6200 SU of straight flat road), a fresh ENGINE 13 with 150 armor on his spot, T1 = 1.6, T2 = 1.0
#   (GM:1665), step counter and escape clock 0. No take depends on the one before it.
# - FTBossNow is sent on a level-clock tick ("FT CLOCK level=<n>", GM:1034: the first frame past each whole second of
#   game time), so his timers sit on the clock's grid: summoned at T, first attack at T+1.6, live at T+2.6 (phase 0,
#   warning 1.0 s) or T+2.45 (phases 1 and 2, warning 0.85 s).
# - Ticks are COUNTED, never named: "waitfor FT CLOCK level=|8" is the next tick after the last console command (the
#   waitfor window starts there, FTGameInstance.cpp:552), and FTDumpLevel is the harmless command that starts a new
#   window. So a stall can cost one take a second, but it cannot leave the script waiting for a number that has gone.
# - Stills: FTFreeze 1 / shot / FTFreeze 0 (time dilation 0.0001, GM:3735). Writing a 3440x1440 PNG stalls the game
#   for one frame of 0.4 to 0.6 s (today's log): frozen, that costs no game time; a still costs about 0.15 game s.
# - The HUD's plates run on the real clock, which goes on while the world is frozen: ACTION! 0.45-1.45 s and the scene
#   name until 2.8 s after play starts (FTHUD.cpp:667-668), the key-hint bar for 10 s (GM:1036), a phase caption for
#   3 s (FTHUD.cpp:650). Where a still would land within a few tenths of one of these going on or off, a "wait"
#   between FTFreeze 1 and the shot lets it pass with the world held, so the same frame has it in both runs.
#   Key-hint bar: ON in enter_*, idle, hurt; OFF from hose_windup on. Scene plate: ON in enter_1/2, OFF in enter_3.
#   Phase caption: ON in phaseN_start, phase1_barrel, phaseN_hose_windup; OFF from phaseN_hose_release on.
# - The car is held in one lane (ft.AutoX) and the hose always takes the car's lane (GM:2881), so every hose goes live
#   ON the car: "FT HURT" (GM:1497; dmg=0.0, FTAutoRun makes the car invulnerable) is its first live frame.
# - Hurting: "FTFire <n> Boss" (FLOW:1031) = n standard rounds through the gun's own hit path in one frame, 1 armor
#   each. 150 armor: 54 -> 96 = 64 % = phase 1; 106 -> 44 = 29 % = phase 2 (GM:2645, strictly above 66 % / 33 %);
#   24 more -> 20 = 13 % = the "running dry" line. With FTAutoRun the car itself never fires (GM:1177).
# - Traffic: a civilian is never called into a lane that has anything more than 130 m ahead in it (GM:1714-1715). In
#   the two long takes a pickup crate is put far ahead on the centre line (FTPickup, FLOW:1068): 3 m to the side of
#   the car, so it is never collected (touch = 2.28 m, GM:2453), and it keeps both centre lanes empty, so nothing can
#   be rear-ended while the fireballs are filmed. The other takes are over before a civilian could reach the car
#   (4.3 s at the least). To have traffic as it comes, delete the four FTPickup lines: no timing hangs on them.
#
