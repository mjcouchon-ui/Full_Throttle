# HOW THE MOMENTS ARE PINNED
# - A still is taken with the world held: FTFreeze 1 / shot / FTDumpLevel / FTFreeze 0. The dump prints
#   "FT LEVEL dump ... clock=<level clock>", the game-time stamp of that still (compare the two runs' stamps).
#   A hold costs 0.15 s of game time and up to two frames (the runner's step after FTFreeze 0).
# - A RELEASE is waited for, not timed: "FT TESLA arcs=" is logged one frame after an attack goes live (GM:2758; once
#   per attack; only the first 20 of a process: this script uses 10). The still is two frames after go-live.
# - What follows a release closely (the landing, a second mark, the wave reaching the car) is timed in 0.3x slow
#   motion (FTSlowMo, FLOW:1065), so that a late frame costs a third as much game time. The slow motion's own clock is
#   REAL time and runs through the holds (TickSlowmo, GM:3729-3736), so each such block ends with a long hold in which
#   it runs out and the time scale is back at 1 before the world is let go: after it wall time is game time again.
# - A WINDUP has no log line, so it is a wall-clock wait at normal speed from the last anchor, taken from the boss's
#   own timers (each wait says which). They have 0.2 s or more to spare on both sides at 30 frames a second; below
#   about 25 frames a second the stills start to slip (run both builds with -Small then).
# - The car is pinned to its start lane (x = 292 cm = lane 2, GM:291) with ft.AutoX (GM:1114), so every attack is
#   aimed at the same place: lane arcs pick the lane nearest the car (GM:2698), the strike mark follows the car (GM:3258).
# - FTAutoRun: the autopilot steers, the car cannot be hurt and never fires (GM:1177), so the boss loses armor only
#   to the FTFire lines below, and his phases change exactly where this script says.
# - The HUD's small plates run on the REAL clock (ACTION! 0.45-1.45 s and the scene's name 2.8 s after a scene starts,
#   a shout 1 s, a caption 3 s, the key hints for the first 10 s of play: FTHud.cpp:650-717, GM:1036). The holds are
#   sized so that no still sits on one of those edges. The DIRECTOR line is real-time chatter and can differ.
# t = game seconds after the SECOND "FT BOSS state=Arrive" (the FTBossNow one).
#
# AFTER A RUN, IN THE LOG: no "result=timeout"; "FT LEVEL id=L2 scene=7"; two "FT BOSS state=Arrive"; no "FT STUNT name=";
# exactly 10 "FT TESLA arcs=" before "FT BOSS state=Down"; FT DAMAGE left=115, left=79, left=39, left=0; FTHITCH lines
# during the fight mean slow frames (then run both again with -Small).
#
