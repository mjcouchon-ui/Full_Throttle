# boss_L8.txt : game level 8 (City Center, level index 7), THE CHAIRMAN: the whole fight, staged for before/after frames.
# Run it the same way on both checkouts (a new -Tag each run, the same frame size):
#   powershell -NoProfile -ExecutionPolicy Bypass -File "K:\Full Throttle\SkyScratch\SourceArt\Jam\unreal\jam_exec.ps1"
#       -Tag <tag> -Script "K:\Full Throttle\SkyScratch\DevLog\jam\overhaul\validate\boss_L8.txt" -Checkout "<project folder>"
#       -BudgetSec 1200 -Extra "-ftnoattract -ftnodynres -ftslot=pie"
# (-ftslot=pie puts the career on the test slot before the first line runs; FTUseTestSlot below does it again.)
# After each run look in the log for:
#   result=timeout                      the script lost its place at that line (none is expected)
#   FT BOSS state=Arrive armor=220      six of them: warm-up, entrance, takes W, BR, P1, P2
#   FT DAMAGE target=Boss .. left=      72 (warm-up), 215 and 145 (take P1), 72 (take P2), then 0 (the defeat)
#   waitfor="FT HURT" result=found      four of them (burst_land and the three rocket_release shots)
#   FT HURT .. near=Civilian            a road car ran into the pinned car inside a take (those frames differ by that)
#   FTHITCH ms=                         a frame over 400 ms between a clock line and its shot costs that shot its moment
#
# HOW IT KEEPS TIME
#  - Script waits are REAL seconds; the boss runs on GAME time. So the long stretches are counted on the game's own
#    clock: "FT CLOCK level=<t>" is logged in the first frame past every whole second of level clock (game time).
#    "waitfor FT CLOCK level=|4" = go on at the next whole second. A waitfor only sees lines logged after the last
#    console command, so a bare "FTFreeze 0" (it does nothing when the world is not held) is put between two of them
#    to count one more second.
#  - The fight is cut into TAKES. Each take: wait for a whole second, then FTBossNow in that same frame = a fresh boss
#    on his spot, car back at the finale line, road cleared, his timers reset (T1=1.6 T3=6.0, Step 0). So in a take the
#    clock lines fall on T = 1.0, 2.0, 3.0 ... ("T" = game seconds since that take's "FT BOSS state=Arrive"), a frame or
#    two late at most, however long the frames before took. Only the last few tenths before a shot are a real wait.
#  - Every still in the fight is FTFreeze 1 / shot / FTFreeze 0: game time stands while the frame is saved. From one
#    still to the next: 0.15 s (the pause after FTFreeze 0) + the wait + 0 to 2 frames.
#  - "FT HURT" = something hit the car (it is invulnerable, the line is still logged, dmg=0.0): used for the moment a
#    burst lands and the moment the rocket ring under the car goes off. Their timeouts are short on purpose: if the
#    line does not come the shot is still taken while that attack is landing.
#  - The car is pinned on road x = 292 cm (ft.AutoX; lane 3, where every race starts), so aimed attacks land on it
#    every run, and SPEED UP is let go (380 su). FTAutoRun: the autopilot steers, the car takes no damage and never
#    fires. The boss is hurt only by "FTFire <n> Boss" (n standard rounds through the gun's real hit path in one
#    frame, 1 armor each on a fresh career) and killed by FTWrapNow.
#
# THE CHAIRMAN's timers (FTGameMode.cpp TickBossLimo): one attack each time T1 runs out, picked by Step:
#  phase 0 (armor above 66%): wall, aimed bursts, rockets x2 ; gap 2.2 s (2.5 after rockets): T = 1.6, 3.8, 6.0, 8.5
#  phase 1 (66% or less)    : wall, bursts, rockets x3, wall ; gap 1.9 s (2.2 after rockets): T = 1.6, 3.5, 5.4, 7.6
#  phase 2 (33% or less)    : wall, bursts, rockets x4, wall ; gap 1.6 s (1.9 after rockets): T = 1.6, 3.2, 4.8, 6.7, 8.3
#  the stream (phase 1 and 2): T3 = 6.0 s after the phase starts, then one shot every 0.2 s (0.14 s in phase 2).
#  wall = 15 shots in one frame (290 su/s, 1.3 s to the car), no warning. bursts = 3 volleys of 3, 0.05 / 0.37 / 0.69 s
#  after T1 (340 su/s, 1.1 s to the car). rockets = rings on the road, live 1.05 s later (+0.2 s for each further
#  ring) for 0.3 s; the first ring is under the car. None of the bullet attacks has a wind-up or a log line today.
