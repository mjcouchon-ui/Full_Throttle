# menus_walk.txt - FULL THROTTLE: every screen of the racing game, filmed for before/after frames, and the
# restart flows proved by log lines. Level 1 (Bayshore) only. Uses only line types, commands and log lines that the
# untouched baseline (OverhaulBaseline, code of 12:11 on 15 Nov 2026) and main both have: no "film" line, no FTGo.
#
# RUN (same line on both checkouts, a new -Tag each time, the same frame size on both):
#   powershell -NoProfile -ExecutionPolicy Bypass -File "K:\Full Throttle\SkyScratch\SourceArt\Jam\unreal\jam_exec.ps1"
#     -Tag menus_before -Script "K:\Full Throttle\SkyScratch\DevLog\jam\overhaul\validate\menus_walk.txt"
#     -Checkout "K:\Full Throttle\OverhaulBaseline\full-throttle-unreal" -BudgetSec 1800 -Small -Extra "-ftnodynres -ftslot=pie"
#   Do NOT pass -ftnoattract (menu_attract* would then show the plain title), -ftauto, -ftday1 or -ftdays.
#   Two map loads (the boot, and RESHOOT LEVEL from the pause menu) plus about eight minutes of script. 132 frames.
#
# TIMING OF THE BURSTS. The runner pauses 0.15 s after a console command and 0.5 s after a shot, in real seconds, so
# at normal speed two shots are never closer than 0.5 s. A burst therefore runs frame by frame:
#     t.MaxFPS 1        one frame a real second, so every script line takes exactly one frame
#     t.OverrideFPS n   every frame is 1/n s of game and menu time whatever it really took (50 = 0.02, 20 = 0.05, 10 = 0.1)
#   and "t.OverrideFPS 0" then "t.MaxFPS 0" ends it (in that order; the frame rate stays uncapped afterwards, on both
#   builds alike). Inside a block a repeated "t.OverrideFPS n" line is one frame of filler, a shot shows the frame
#   after its own line, and there is no "wait" (real seconds would break the frame count). The same script
#   therefore films the same menu times on both builds, however fast either one runs, at either frame size.
#   _seqN is at (seconds after the screen opened):
#     title, preprod_skills, attract, card, rating, paycheck:  0.04 0.14 0.24 0.34 0.44 0.54
#     options, controls, pause (a key opens them), preprod_garage:  0.02 0.12 ... 0.52 (or one frame, 0.02, earlier)
#     reel:  0.05 0.15 ... 0.55 after FT SCREEN name=Reel          hud:  0.10 0.20 ... 0.60 after the slate ends
#       (ACTION! replaces the scene's name 0.45 s in)
#     card_clap (the same take as card, straight on):  0.64 ... 1.14   (the clapper shuts 0.88-1.0, sweep to 1.22)
#     cut:   0.55 ... 1.05 after the wreck      (the CUT! card comes in at 0.6)
#     wrap:  0.75 ... 1.25 after FTWrapNow      (the card comes in at 0.8)
#     rating_stamp:  2.64 ... 3.14 on THE DAILIES (the stamp lands at 2.7)
#   CHECK in the log: inside a block every "FT EXEC line=" must be one frame after the one before it (the [nnn]
#   column). A line that took two frames (a stall of most of a second) puts the rest of that burst one step late.
#   The stills are taken at normal speed, by real seconds: they pair by moment, not by pixel.
#
# WAITFOR only sees log lines printed after the script's last console command (t.MaxFPS and friends included), so
# every waitfor here follows the command that causes its line, or waits for something still to come.
#
# AFTER THE RUN: the log must have no "result=timeout" (each one means the script lost its place there), and:
#   title ENTER        : FT TITLE start level=1 attract=0, then FT LEVEL id=
#   options, controls  : FT TITLE overlay=Options twice, FT TITLE overlay=Controls twice
#   pre-production     : FT SKILL id=CAR1 state=PENDING then state=UNDONE; FT SCREEN name=PreProduction tab=1 .. tab=4
#   attract            : FT ATTRACT shot twice (the boot's own and this script's)
#   pause              : FT SCREEN name=Pause state=opened three times, state=resumed twice
#   pause, RESHOOT (R) : FT MUTE reapplied .. map=L_Bayshore a second time (the map was loaded again) with FT LEVEL id=
#                        beside it, then FT LEVEL dump .. take=1 retakes=0 .. score=0
#   wreck, retake      : FT PLAYER wrecked retakes=1 (then 2), FT CARNAGE .. retake=1, FT LEVEL dump .. take=2
#   wrap to paycheck   : FT OUTCOME wrap, FT RATING value=, FT SCREEN name=Reel, .. Reel state=hold, .. Dailies, .. Paycheck
#   paycheck R reshoot : FT SCREEN name=PreProduction next=L1, FT SCREEN name=Slate next=L1, FT LEVEL id=
#   hold to skip reel  : FT INPUT screen=Reel key=Enter result=hold
#   dailies ESC, title : FT SCREEN name=PreProduction next=Title, FT SCREEN name=Title banner=""
#   FT LEVEL id= nine times in all; FT MUTE reapplied twice.
# NOT THE OVERHAUL if they differ between the two runs: the BEST lines on the title rows, the FPS counter, MUTED and
# reduced motion (no entrances at all) come from each checkout's own Saved\FullThrottle\settings.json.
